# Adversarial review 1: fixes

Fixes for every finding of [`adversarial-review-1.md`](adversarial-review-1.md), on branch
`ws/w4fix`. Rule applied throughout: user data safety first (reversible over irreversible,
skip over guess, report over act). Each regression test fails on the reviewed code and
passes after the fix (checked by reverting the fix locally before committing).

## Behaviour changes users will notice

- "Select all" in a duplicate (or any grouped) step leaves each group's kept copy unchecked; its label says so. A group with every copy checked is skipped and the checklist says why.
- Folder rows that hold a protected path, `.git`/`.hg`/`.svn`/`.bzr` (outside artefact folders), `.ssh`/`.gnupg`/`.aws`/... or a MyJanitor folder are locked as protected; a folder that changed since the scan, holds online-only files or content the scan did not see (exclusions, hidden files when hidden is off, depth limit) is skipped as `changed`/online-only.
- Hard-link replacement asks for confirmation (dialog with its own wording, `--confirm-lossy` in the CLI) and cannot be scheduled.
- Undo of an optimisation or archive refuses when the output was edited since, even with the same size; restores refuse an item whose content is not what was moved.
- A second MyJanitor (CLI or scheduled run while the GUI is open) can read but not change files; a second GUI window does not open. An unreadable journal blocks every acting command with an actionable message.
- On Windows, names ending in a dot or space, or shaped like 8.3 short names, are skipped.
- Media files whose content matches no known container are skipped by the audio/video optimisers.
